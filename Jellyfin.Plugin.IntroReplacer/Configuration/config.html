Intro Replacer

Rules are evaluated top to bottom; the first enabled matching rule wins. An empty condition matches everything. The custom intro plays first, then the episode/movie starts. With Replace the item's own intro is skipped; with Prepend the item plays from the beginning.

Settings

Used by "once per session": if no intro played for this long, the next one starts a new session.

Intro files

Uploaded videos are stored in the plugin data folder and can be picked in rules below.
